## 📌 Project Description

Hangman is a word-guessing game where the player has to guess the hidden word one letter at a time.

The player gets a limited number of incorrect guesses. The game ends when the player correctly guesses the word or uses all the allowed attempts.

## ✨ Features

* 🎯 Random word selection
* 🔤 Letter-by-letter guessing
* ❤️ Limited incorrect guesses
* 📊 Displays guessed letters
* 🏆 Win and lose messages
* 🔄 New Game option
* 🌐 Interactive Streamlit interface

## 🛠️ Technologies Used

* **Python**
* **Streamlit**

```bash
python -m streamlit run app.py
```

## 🎮 How to Play

1. Open the game.
2. Guess one letter at a time.
3. Correct letters appear in the hidden word.
4. Incorrect guesses reduce your remaining attempts.
5. Guess the complete word before your attempts run out.
6. Click **New Game** to play again.
